Prepared for Jack Blair · Happy Jack Media · 2026-09-10

Executive summary

The network is not the problem. Splitting a 14B model across two Macs over wired gigabit ran faster than the same host alone: +14% decode, +15% prefill. With 95% of the model pushed to the worker it hit 31.4 tok/s — beating that worker's own solo score of 26.8. Sub-millisecond LAN hops cost less than the memory-bandwidth they free up.

The headline goal was not reached. Every run of a model that actually needs pooling (32B Q8, 70B Q4) failed. Overnight this looked like a Metal-worker bug; the shard-size ladder proved it was a device-order inversion in --tensor-split (RPC devices first, local GPU last). Corrected, the 14B runs at every split. One genuine blocker remains: 32B Q8_0 still fails (res = -3) before any worker compiles a kernel, with every node well inside its memory. Leading hypothesis: Q8_0 through the RPC backend. A 10-minute discriminator (14B at Q8_0) is queued and decides the next step.

Fleet reality check. Usable GPU memory on Apple Silicon under RPC is ~65% of RAM, not 75%. A "24 GB" daily-driver Mac in use benchmarks 40% below the identical idle chip. Heimdall's CPU can't be the fallback path (93 °C in two minutes). Jotunheim (M1 Pro) is exactly half an Odin and still worth ~8 GB of pool capacity. Halo's capability records need measured free GPU memory and per-chip bandwidth, not spec-sheet numbers.

6 · What Halo learned · and what's next

Confirmed findings
  • LAN pooling has no speed penalty and can be a gain; the bottleneck was memory ceilings and software, never the network.
  • Apple Silicon usable Metal budget under RPC ≈ 65% of RAM; it fails late (allocates, then dies at first compute).
  • Load matters as much as chip: identical M4 Pros differed by 40%. Capability records need measured free GPU memory.
  • Weak nodes are still worth pooling at a proportional cost (Jotunheim ≈ 8 GB of capacity, ~40 ms/token).
  • Heimdall's RTX 4070 is a reliable CUDA worker (6–9 GB shares, zero failures). Its CPU is not a fallback path.
  • 11 operational gotchas documented (split syntax, macOS Local Network privacy for nohup, single-client workers, Wi-Fi routing, etc.).
Test 01b — queued
