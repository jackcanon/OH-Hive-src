# Independent coding checker

Owner-selected named coding tasks now capture a bounded review package while holding their checkout lock. It includes the original task, protected preparation baseline, every tracked change against that baseline (including later local commits), visible untracked text files, before/after contents, prior host acceptance receipt, coder report and reported model. A digest binds the entire package. Reserved package receipt lines supplied by the coder are discarded; only host capture can append the package.

A completed task with a valid package offers “Request independent check.” Select a different owned, active local agent, its execution computer and model. Saving creates a separate durable dependent task. Prepare validates the package without downloading a repository; Run uses the ordinary explicit private operation, target, identity, lease, capacity and cancellation controls. Duplicate owner requests do not create extra tasks. The source result is revalidated before execution; changing it, revoking the host or archiving/reassigning the checker prevents execution.

The checker receives the frozen package and its saved owner-selected context, with no tools. Tool requests are rejected without execution. It must return a bounded structured verdict: pass, changes_required or inconclusive. The host supplies a deterministic source-line map to help the model cite accurately. Findings still require an exact source excerpt on a valid cited line; an invalid citation blocks review. Pass requires prior passed required host checks. The host binds the receipt to both agent/task identities and the package digest. The task list presents a human-readable verdict rather than the raw package.

This is an independent model review, **not an independently rerun test suite**. A completed checker task may report changes_required or inconclusive; its queue status does not mean code approval. It never edits, merges, publishes, marks a project complete or automatically dispatches a correction. A verdict concerns the saved snapshot; later checkout changes require a fresh coding/checker attempt. Scope is twenty UTF-8 text files and a 48 KiB package, with bounded capture time. Git-ignored files, binary assets, symbolic links, submodules and legacy preparation receipts without a protected baseline are outside this first release. Oversized/unsupported capture reports review unavailable rather than silently truncating evidence. Local coding still uses trusted real subprocesses; this change does not sandbox the coder.

Validation: core regression suite, workspace production lint, matching native bridge and signed desktop build; live Helheim negative/positive controls are recorded separately. No model inference on Midgaard. Automatic coordinator-to-coder-to-checker correction and research review remain subsequent work.
